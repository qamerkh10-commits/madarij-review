# متابعة المراجعة — مدارج

نظام متابعة مراجعة المحاضرات: لوحة تحكم، ومهام المراجعين، وإرسال الدفعات عن طريق بوت تليجرام، وإدارة الفريق والصلاحيات، وسجل النشاط.

- الدخول بحساب تليجرام: ابعت `/login` لبوت المراجعة واضغط «🔐 ادخل الموقع».
- الصفحة نفسها مفيهاش أي بيانات أو مفاتيح. البيانات كلها في Google Sheet، والصلاحيات بتتراجع على السيرفر (Google Apps Script) في كل طلب.
